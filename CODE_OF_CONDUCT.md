# Code of Conduct

This project follows a simple code of conduct focused on academic collaboration.

Participants are expected to:

- Be respectful and professional.
- Provide constructive feedback.
- Avoid offensive, discriminatory, or inappropriate language.
- Respect dataset usage and citation requirements.
- Avoid uploading unrelated, private, or copyrighted material without authorization.

Issues or pull requests that do not follow these principles may be closed.
