# Release v1.0.0 - Ataulfo Mango Maturity Dataset

This release contains the complete Ataulfo mango image dataset organized by maturity class.

## Files

The complete image dataset is available in the GitHub Releases section:

https://github.com/Imanol-24/ataulfo-mango-maturity-dataset/releases/tag/v1.0.0

## Dataset organization

The image dataset is organized by class and is not pre-divided into training, validation, or test subsets.

Each user must define their own experimental protocol and generate their own partitions.
