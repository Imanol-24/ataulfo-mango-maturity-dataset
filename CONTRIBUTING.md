# Contributing

Thank you for your interest in this repository.

This repository is primarily intended to provide the Ataulfo mango dataset, extracted feature datasets, and reproducible code associated with the corresponding research article.

## How to contribute

You may contribute by:

- Reporting errors in the code or documentation.
- Suggesting improvements for reproducibility.
- Proposing clearer usage examples.
- Reporting issues with dataset download or file structure.

## Pull requests

Before submitting a pull request:

1. Make sure the code runs without errors.
2. Do not include generated outputs, trained model weights, or large image files.
3. Keep the existing folder structure.
4. Clearly describe what changed and why.

## Citation

If your work uses this repository, the dataset, CSV feature datasets, code, or any derived resource, please cite the associated paper.
